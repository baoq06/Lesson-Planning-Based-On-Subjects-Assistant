## 2. Foundational Theory & System Architecture
### 2.1. The nature of the ReAct Pattern (Reasoning + Acting)
ReAct combines internal logical reasoning with the ability to interact with the external environment:
- **Thought**: The agent asks itself and plans: *"What information do I need? What should the next step be?"*
- **Action**: The agent triggers a specific tool with the corresponding parameters (for example `search_lesson_plan(week=4)`).
- **Observation**: The system executes the tool and returns the real result to the agent as input for the next thinking step.
- The cycle repeats until the agent decides it has enough evidence to output the **Final Answer**.

### 2.2. Agent Loop architecture & Safe Tool Execution
- **Agent Loop Termination**:
  Without a stopping point, an agent can fall into an infinite loop (Infinite Tool Call Loop). A `for step in range(MAX_STEPS)` loop with `MAX_STEPS = 6` is mandatory to bound cost and resources.
- **Safe Tool Execution principle**:
  A tool exception must never crash the agent. All tool-calling code must be wrapped in `try...except`. If an error occurs (for example wrong parameters, lost connection), return the string:
  `"Error executing tool '<name>': <error_message>"`
  The LLM reads this error string in the next iteration as an Observation and corrects the parameters to call again.
- **Security prohibition**: Never use `eval()` or execute untrusted code generated by the LLM.

### Exercise 6.2 — Safe Tool Execution with exception handling (src/agent/react_agent.py)
```python
async def safe_execute_tool(tool_fn, **kwargs) -> str:
    try:
        result = await tool_fn(**kwargs)
        return str(result)
    except Exception as e:
        # Catch every exception and return an error description so the LLM can recover
        return f"Error executing tool: {type(e).__name__} - {str(e)}"
```

### Exercise 6.3 — Complete ReAct loop (ex2_1_react.py)
```python
def run_react_agent(user_question: str, max_steps: int = 6):
    messages = [
        {"role": "system", "content": "You are a ReAct Agent for the AIPR course. Reason step by step."},
        {"role": "user", "content": user_question}
    ]
    for step in range(max_steps):
        resp = client.chat.completions.create(
            model="qwen/qwen3.8-27b",
            messages=messages,
            tools=tools,
            temperature=0.0
        )
        msg = resp.choices[0].message
        messages.append(msg)

        if not msg.tool_calls:
            return msg.content  # Final Answer

        for tool_call in msg.tool_calls:
            # Execute and append the Observation to messages
            obs = execute_tool(tool_call.function.name, tool_call.function.arguments)
            messages.append({
                "role": "tool",
                "tool_call_id": tool_call.id,
                "content": obs
            })
    return "The maximum number of reasoning steps was exceeded."
```

## 4. Common Pitfalls & Design Principles (Gotchas & Best Practices)
- **Tool Arguments that are not valid JSON pitfall**: The LLM occasionally returns a JSON string with a syntax error; use `json.loads` inside a `try...except` block to catch the parse error.
- **Context Blowup pitfall**: With every ReAct step the `messages` list grows multiplicatively; you need to filter or trim observations that are too long.
