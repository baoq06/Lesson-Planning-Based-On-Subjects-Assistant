## 1. Mô tả học phần
Nghiên cứu phát triển ứng dụng Web toàn diện Full-stack: Frontend hiện đại (HTML5, CSS3, JavaScript ES6+, React), Backend RESTful API (Node.js/Express hoặc Python FastAPI), xác thực JWT và triển khai sản phẩm.

## 2. Chuẩn đầu ra học phần (Course Learning Outcomes - CLO)
- CLO1: Xây dựng giao diện web chuẩn Responsive Web Design bằng HTML/CSS/JS.
- CLO2: Phát triển Backend API chuẩn RESTful kết nối CSDL có xác thực bảo mật.
- CLO3: Xây dựng ứng dụng web Single Page Application (SPA) với React/Next.js.

## 3. Kế hoạch giảng dạy chi tiết theo tuần (Lesson Plan)
### Tuần 1: Kiến trúc Web: HTTP/HTTPS, DNS, Mô hình Client-Server và HTML5 Semantic Tags
- **Tài liệu học tập / Đọc trước**: Chương 1 Nền tảng Web
- **Hoạt động & Đánh giá**: Tạo trang cấu trúc bài báo chuẩn Semantic HTML5

### Tuần 2: CSS3 hiện đại: Box Model, Flexbox, CSS Grid và Responsive Web Design (Media Queries)
- **Tài liệu học tập / Đọc trước**: Chương 2 CSS3
- **Hoạt động & Đánh giá**: Thiết kế Landing Page chuẩn Responsive trên Mobile và Desktop

### Tuần 3: JavaScript ES6+: DOM Manipulation, Event Handling, Arrow Functions, Promises, Fetch API
- **Tài liệu học tập / Đọc trước**: Chương 3 JavaScript
- **Hoạt động & Đánh giá**: Viết ứng dụng To-Do List có lưu trạng thái vào LocalStorage

### Tuần 4: Nhập môn Frontend Framework: Thư viện React, JSX, Virtual DOM và Khởi tạo dự án Vite
- **Tài liệu học tập / Đọc trước**: Chương 4 React Cơ bản
- **Hoạt động & Đánh giá**: Xây dựng các Component hiển thị danh sách sản phẩm

### Tuần 5: Quản lý trạng thái trong React: useState, useEffect, Custom Hooks và Props Passing
- **Tài liệu học tập / Đọc trước**: Chương 4 React State
- **Hoạt động & Đánh giá**: Lấy dữ liệu từ API bên ngoài và render với hiệu ứng tải

### Tuần 6: Điều hướng trang với React Router và Quản lý Form (React Hook Form)
- **Tài liệu học tập / Đọc trước**: Chương 4 React Router
- **Hoạt động & Đánh giá**: Tạo luồng điều hướng giỏ hàng và thanh toán

### Tuần 7: Thi giữa kỳ trên máy (Xây dựng giao diện Frontend hoàn chỉnh 90 phút)
- **Tài liệu học tập / Đọc trước**: Phòng máy thi
- **Hoạt động & Đánh giá**: Đánh giá kỹ năng HTML/CSS/JavaScript/React

### Tuần 8: Xây dựng Backend: Node.js/Express.js hoặc Python FastAPI, Cấu trúc dự án MVC
- **Tài liệu học tập / Đọc trước**: Chương 5 Backend API
- **Hoạt động & Đánh giá**: Tạo các endpoint CRUD sản phẩm trả về JSON

### Tuần 9: Kết nối CSDL từ Backend: Tích hợp ORM (Prisma/TypeORM/SQLAlchemy) và Migrations
- **Tài liệu học tập / Đọc trước**: Chương 6 CSDL Backend
- **Hoạt động & Đánh giá**: Viết truy vấn lọc, tìm kiếm và phân trang dữ liệu từ DB

### Tuần 10: Bảo mật và Xác thực: Đăng nhập/Đăng ký với Bcrypt mã hóa mật khẩu và JSON Web Token (JWT)
- **Tài liệu học tập / Đọc trước**: Chương 7 Auth & Security
- **Hoạt động & Đánh giá**: Tạo Middleware bảo vệ các Private Route cho người dùng

### Tuần 11: Tích hợp Full-stack: Kết nối Frontend React với Backend API, Xử lý CORS và Upload ảnh
- **Tài liệu học tập / Đọc trước**: Chương 8 Tích hợp
- **Hoạt động & Đánh giá**: Hoàn thiện luồng mua hàng và quản lý đơn hàng

### Tuần 12: Triển khai ứng dụng (Deployment trên Vercel/Render) và Báo cáo đồ án website cuối kỳ
- **Tài liệu học tập / Đọc trước**: Hội đồng chấm đồ án
- **Hoạt động & Đánh giá**: Bảo vệ đồ án website Full-stack trực tuyến
